### Install locally

Copy or symlink a skill into your Cursor skills directory, for example:

```bash
ln -s "/Volumes/Saviour/Projects/ai-skills/engineering-principles" ~/.agents/skills/engineering-principles
```

Or add this repo’s skills path to your Cursor skill configuration.
